🚧

## Run locally

🚧

### Requirements
```
Node: >= 22.14.0
```

<br />


1. Copy .env to .env.local
```bash
cp .env .env.local
```
2. Install Corepack
```bash
npm install --global corepack@latest
```
3. Use pnpm
```bash
corepack enable pnpm
```
4. Install dependencies
```bash
pnpm install
```
5. Run
```bash
pnpm run dev
```
The app should start at: http://localhost:3000/
